# Android tree goldens

No Android screens are captured yet. Capture them on `Offsider_E2E_Pixel_9` with the same command as iOS (see `Tests/Goldens/README.md`), using `OFFSIDER_ANDROID_E2E=1`, `OFFSIDER_ANDROID_DEVICE` and `OFFSIDER_ANDROID_APK` in place of the iOS variables. Each screen gets the same four files, and the tests then require the same screens on both platforms.
